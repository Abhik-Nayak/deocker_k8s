The request path

One browser request crosses three separate worlds. The cluster is the middle one, not the whole picture.

  1. Browser hits localhost:8080. Nothing is listening on your machine except the port-forward process.
  2. port-forward tunnels the bytes through the API server. This is an API call, not a network route — which is why it works when NodePort doesn't.
  3. The API server hands the stream to one client Pod, chosen from the Service's endpoints.
  4. nginx serves static files itself. The React bundle never touches the backend.
  5. Only /api/ is proxied to http://api:8000, resolved by cluster DNS to the api Service, which load-balances across both api Pods.
  6. The api Pod opens a TLS connection to RDS over the public internet, leaving through Docker's NAT.

Against your sketch

Correct

Everything you drew was accurate

Registry, three nodes, both ConfigMaps and Secrets, the succeeded migrate Pod, and both Services with their exact ClusterIPs and Pod names all match the live cluster. The control-plane / worker split is right too.

Missing

The database

Step 4 prepared "the database," but it wasn't anywhere in the drawing — because it isn't in the cluster. It's RDS in ap-south-1, reached over the public internet.

Missing

The way in

Nothing showed how a browser reaches any of this. The answer is port-forward through the API server — and notably not the NodePort you'd expect.

Missing

The two Services are chained, not parallel

Drawing both on a shared "internal network" cloud reads as siblings. The frontend calls the backend: nginx inside the client Pod proxies to api:8000. That's why the Service must be named exactly api.

Missing

Deployment → ReplicaSet → Pod

You drew Pods and Services but not what creates the Pods — the layer that gives you self-healing and rollbacks. It's already encoded in the names you wrote down.

Nuance

Two small things

kube-root-ca.crt isn't yours — Kubernetes auto-creates it in every namespace. And Docker Desktop created this cluster, not you, which is exactly why kind get clusters prints nothing.
